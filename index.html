Add a Mapbox access token

The atlas is built and ready — it just needs a token to draw the basemap. Mapbox's free tier covers 50,000 map loads a month and needs no card to start.

  1. Create an account at account.mapbox.com.
  2. Copy the default public token (it starts with pk.) from your account page.
  3. Paste it below to try it right now, or set it permanently in config.js.

Trying a token here keeps it in this browser only (localStorage) — nothing is sent anywhere but Mapbox.
